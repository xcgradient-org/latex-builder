\section{Repository Architecture and Documentation}
This section synthesizes the core structure and operational guides of the repository to provide a clear technical roadmap for future researchers seeking to reproduce or extend this pipeline.

\subsection{Project Overview}
The repository contains the comprehensive research codebase evaluating the downstream utility of synthetic data generated via the CART method. It is structured into two main experimental domains, directly corresponding to the two studies presented in this thesis:
\begin{itemize}
    \item \textbf{Clustering Study}: Evaluates structural utility using K-Means and Hierarchical Clustering.
    \item \textbf{Regression Study}: Evaluates inferential utility using Linear and Logistic regression models across continuous and binary predictors.
\end{itemize}

\subsection{Directory Structure}
To maintain isolation between the experimental frameworks, the repository is logically divided by study. Both studies share a unified installation procedure but maintain independent execution environments:

\begin{verbatim}

\section{Environment Setup and Execution}
\label{sec:app-setup}

The project utilizes both \textbf{R} and \textbf{Python} to generate synthetic data and evaluate machine learning models. The environment setup is fully documented and can be bootstrapped autonomously.

\subsection{Prerequisites and Installation}
The pipeline requires the following base dependencies:
\begin{itemize}
    \item \textbf{Conda} (Miniconda or Anaconda) for environment management.
    \item \textbf{R} (version 4.0+) for the \texttt{synthpop} engine.
    \item \textbf{Python} (version 3.9+) for clustering and regression fitting algorithms.
\end{itemize}

Researchers can set up the required environment using the provided installation scripts:

\begin{verbatim}
# 1. Create and activate the Conda environment
conda create -n synthetic_data python=3.9
conda activate synthetic_data

# 2. Install required Python and R packages
pip install pandas numpy scikit-learn matplotlib seaborn scipy pyarrow fastparquet
R -e 'install.packages(c("synthpop", "jsonlite", "mvtnorm", "dplyr", "parallel", "arrow"))'
\end{verbatim}

\subsection{Executing the Pipelines}
To execute either study, researchers must navigate to its respective directory and run the master script (\texttt{run\_all.sh}), which handles generation, processing, and evaluation sequentially.

\vspace{0.3cm}
\noindent\textbf{Clustering Execution}
\begin{verbatim}
cd clustering/
./run_all.sh
\end{verbatim}

\vspace{0.3cm}
\noindent\textbf{Regression Execution}
\begin{verbatim}
cd regression/
./run_all.sh
\end{verbatim}
